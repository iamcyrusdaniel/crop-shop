# crop-shop
a game about selling your crops, but YOU are the seller and you need to manually put them in the cart/grid till all of the space is used!

**Time to sell the harvest!**

## How to play

1. pick a level
2. drag the crops into the grid
3. enjoy the amazing sound effects
4. fit everything in
5. submit your amazing cart
6. enjoy even more amazing sound effects
7. next level!

## What's there?

- different crops with different sizes/shapes
- drag and drop placement
- multiple levels
- level selection screen
- grid snapping
- submitting
- funny sound effects
- a guide
- awesome confetti
- background music
- random background particles
- modern and clean looking design
- custom styling
- interactive buttons
- all in the browser :D
- local storage saving
- walls that spice up levels
- placement highlighting

## Made with

- HTML
- CSS
- JS

We didn't use any frameworks or libraries (not sure if those both are the same thing) other than canvas confetti, just vanilla JS :D
